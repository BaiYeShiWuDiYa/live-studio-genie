# LIVE Studio Genie 功能实现状态与操作指南

本文档基于当前 `main` 分支实现整理，用于比赛演示、功能验收和后续开发交接。

## 1. 状态说明

- **已实现（真实能力）**：接入浏览器、MediaPipe 或 Web Audio 的真实运行能力。
- **已实现（Demo/Mock）**：交互链路完整，但业务数据由本地模拟器生成。
- **部分实现**：已有可演示的相近能力，但尚未覆盖完整需求。
- **未实现**：当前界面和数据层均没有对应能力。

## 2. 通用能力实现总览

按 Demo 演示口径统计：**11 项已实现、2 项部分实现、1 项未实现**。

| 分类 | 能力 | 状态 | 当前实现 |
| --- | --- | --- | --- |
| 监控 | 画面亮度 | 已实现（真实能力） | 摄像头画面中心区域 Canvas 采样，每 900 ms 更新亮度评分。 |
| 监控 | 麦克风声音 | 已实现（真实能力） | Web Audio 分析麦克风 RMS 和 dB，每 250 ms 更新，支持静音状态。 |
| 监控 | 人像占比 | 已实现（真实能力） | MediaPipe Face Landmarker 计算人脸占比、居中、远近和垂直位置。 |
| 监控 | 进房人数 | 已实现（Demo/Mock） | `AudienceEventAdapter` 每 3.5 秒生成近一分钟进房人数。 |
| 监控 | 观众结构（性别/年龄） | 未实现 | 当前 Adapter 和界面均没有性别、年龄字段及统计图。 |
| 监控 | 评论区关键词检测 | 已实现（Demo/Mock） | 对评论进行声音、画面、网络、点播、正向反馈五类关键词聚合。 |
| 组件 | 游戏投屏 | 已实现（真实能力） | 使用 `getDisplayMedia` 选择屏幕、窗口或浏览器标签页。 |
| 组件 | 场景模板/画布布局 | 部分实现 | 播前有单人竖屏/秀场舞台选择；投屏后支持摄像头画中画拖拽、缩放、锁定和重置。模板选择目前偏演示态。 |
| 组件 | 亮度调节滑杆 | 已实现（真实能力） | 支持预览、应用和撤回，通过 Canvas/CSS 滤镜作用于画面。 |
| 组件 | 对比度调节 | 已实现（真实能力） | 支持预览、应用和撤回，也可由 Genie 生成参数。 |
| 组件 | 设置 LIVE Goal | 已实现（Demo/Mock） | 支持预览、发布、自动增长、模拟礼物助力、完成状态和撤回。 |
| 组件 | 美化工具 | 已实现（真实能力） | 包含虚拟背景、美颜、美妆、人脸道具和整套风格。处理均在浏览器本地完成。 |
| 组件 | 麦克风声音调节 | 已实现（真实能力） | Web Audio `GainNode` 支持 -20 dB 至 +20 dB 试听、应用和撤回。 |
| 组件 | 发起观众心愿 | 部分实现 | 已有点歌投票，可用于二选一/多选一互动；尚无自由文本心愿收集、聚合和管理组件。 |

## 3. 数据真实性边界

### 3.1 真实数据

- 摄像头画面与摄像头亮度。
- 麦克风音频、电平、静音和增益。
- 人脸关键点、人像占比和构图状态。
- 屏幕、窗口或标签页投放。
- 本地美颜、美妆、虚拟背景和人脸道具。
- 配置 API Key 后的 Genie 模型请求。

### 3.2 模拟数据

- 在线观众数、近一分钟进房人数和评论密度。
- 实时评论、礼物动态和评论关键词洞察。
- PK 对手、比分和倒计时。
- LIVE Goal 的自动增长与“模拟礼物 +250”。
- 投票由当前浏览器点击模拟，不连接真实直播间评论。

### 3.3 当前缺口

- 真实直播间 IM、进房、礼物和观众画像数据源。
- 观众性别、年龄分布。
- 独立的观众心愿征集、文本聚类、排序和完成状态。
- 真实推流、真实连麦 PK 和服务端直播状态同步。

## 4. 启动与权限

### 4.1 启动项目

环境要求：

- Node.js 20+
- npm 10+
- 最新版 Chrome 或 Edge

在项目根目录执行：

```bash
npm install
npm run dev
```

打开终端显示的地址，默认是：

```text
http://localhost:5173
```

### 4.2 浏览器权限

首次进入工作台后允许：

- 摄像头权限：用于真实预览、亮度、人像占比、美颜、美妆和道具。
- 麦克风权限：用于声音电平、静音和增益调节。
- 屏幕共享权限：点击“游戏投屏”后，由浏览器弹窗选择目标窗口。

拒绝权限不会阻断页面，其对应指标会显示未连接、设备不可用或演示画面。

## 5. 推荐完整体验路径

### 5.1 首页与工作台生成

1. 打开首页。
2. 选择“聊天陪伴”“音乐现场”“游戏直播”或“其他”。
3. 在“本场主题”中输入直播主题。
4. 点击“召唤精灵”进入开播准备。
5. 熟悉流程时可点击“我很熟，直接进入专业模式”跳过主题选择。

### 5.2 完成播前准备

右侧依次完成四项任务：

1. 在“单人竖屏”和“秀场舞台”之间选择布局，点击“确认当前布局”。
2. 查看暖色和磨皮建议，点击“应用画面预览”。
3. 展开首 30 秒口播，确认标题和开场脚本。
4. 查看点歌投票预览，点击“添加点歌投票”。
5. 准备度达到 100 后点击“保存配置”。
6. 在弹窗中点击“GO LIVE”进入直播控制台。

播前任务当前主要用于展示工作流，部分选项尚未持久化为独立场景模板。

## 6. 直播控制台操作

### 6.1 监控指标

进入“直播控制台”后，左侧“演示场景”可切换：

- **画质**：显示真实画面亮度和人像占比。
- **互动**：显示 Mock 评论密度和近一分钟新观众进入数。
- **排障**：显示真实麦克风电平和 Mock 评论关键词反馈。
- **PK**：显示模拟 PK 状态及 LIVE Goal 建议。

实时评论区可独立滚动，不会带动整页滚动。评论、礼物、观众数和进房人数每 3.5 秒更新一次。

### 6.2 摄像头与麦克风

- 点击“开启摄像头”重新请求设备权限。
- 摄像头连接后，按钮显示“摄像头已连接”。
- 点击“麦克风”可静音，再次点击恢复。
- 左侧切换到“排障”可查看实时 dB。

### 6.3 BGM

1. 点击“播放 BGM”启动本地生成的环境和弦。
2. 切换到“排障”场景。
3. 在右侧调整“麦克风”和“BGM”滑杆。
4. 先点击“预览调整”，确认后点击“确认音频调整”。
5. 已应用后可点击“撤回最近一次调整”。

### 6.4 游戏投屏与画中画

1. 点击“游戏投屏”。
2. 在浏览器弹窗中选择屏幕、游戏窗口或标签页。
3. 应用会自动切换到“Studio 视图”，摄像头显示为画中画。
4. 点击“编辑布局”后拖动画中画，拖动边缘调整尺寸。
5. 点击“锁定布局”结束编辑。
6. 编辑状态下点击“重置布局”恢复默认位置和尺寸。
7. 点击“停止投屏”，或使用浏览器共享栏停止共享。

浏览器不保证所有独占全屏游戏都能被捕获，比赛演示建议共享普通窗口或浏览器标签页。

### 6.5 画面亮度与对比度

1. 左侧选择“画质”。
2. 右侧调整“补光”“对比度”“暖色”滑杆。
3. 点击“预览调整”查看临时效果。
4. 点击“应用柔光方案”保存参数。
5. 点击“撤回最近一次调整”恢复上一次正式参数。

预览参数不会直接覆盖已提交配置；切换场景时会清理未应用的预览。

### 6.6 美化工具

点击底部“美化工具”，右侧提供五个 Tab：

- **整套**：清透日常、甜美直播、舞台高光、未来科技，并显示全部微调项。
- **美颜**：原生、自然、柔焦、亮颜。
- **美妆**：无妆、裸妆、甜美、舞台、冷感。
- **道具**：无道具、星光、科技眼镜、黑色墨镜、爱心、星星、蝴蝶和闪电贴纸。
- **背景**：原始、虚化、纯色，以及霓虹直播间、夜间音乐房、未来竞技场、创作者空间。

美颜滑杆：

- 柔肤、提亮、暖肤、对比度、饱和度。
- 美白、红润、清晰。

美妆滑杆：

- 口红、腮红、眼影，可同时调整颜色和强度。
- 眼线、高光。

操作顺序：

1. 选择整套预设，或分别选择美颜、美妆、道具和背景。
2. 调整滑杆时进入预览状态。
3. 点击“应用美化方案”提交当前效果。
4. 点击“撤回最近一次调整”恢复上一次效果。

摄像头原始画面不会上传给模型。MediaPipe 推理和 Canvas 合成都在浏览器本地执行。

### 6.7 互动投票

方式一：

1. 点击底部“互动组件”显示投票预览。
2. 右侧点击“发布互动挂件”。
3. 在画面中的选项按钮上模拟投票并查看百分比。
4. 投票会在设定时间结束后自动收起。
5. 再次点击底部按钮可手动隐藏组件。

方式二：

1. 左侧选择“互动”。
2. 使用右侧 Genie 推荐的点歌投票。
3. 按“预览调整”与“发布互动挂件”完成上屏。

当前投票点击发生在主播端 Demo，不读取真实评论数字。

### 6.8 PK 与 LIVE Goal

1. 点击底部“发起 PK”，画面切换为双人模拟 PK。
2. 右侧显示“本轮冲刺目标”。
3. 点击“预览调整”查看目标挂件。
4. 点击“发起冲刺目标”正式上屏。
5. 目标每 3 秒自动增加 120 分。
6. 点击画面中的“模拟礼物 +250”加速进度。
7. 达标后显示“目标达成”。
8. 点击“结束 PK”返回普通直播画面。

PK 对手、比分和目标增长均为前端模拟，不会创建真实连麦。

## 7. Genie AI 操作

### 7.1 配置

在项目根目录创建 `.env`：

```env
GENIE_MODEL_AK=你的模型访问密钥
GENIE_MODEL_BASE_URL=https://aidp-i18ntt-sg.tiktok-row.net
```

修改环境变量后需要重启开发服务器。

### 7.2 使用方式

在右下角输入问题并按 Enter，或点击发送按钮。示例：

```text
画面亮度加 10，对比度加 5，暖色加 3
麦克风提高 6 dB，BGM 降低 4 dB
创建一个“下一首唱什么”的投票
发起一个 10000 分的 LIVE Goal
根据当前亮度给我一套自然美颜
柔肤 20，美白 15，口红 30，戴黑色墨镜
```

模型可生成以下可信组件：

- 画面调节
- 音频调节
- 相机美化
- 观众投票
- LIVE Goal

生成组件后仍需经过“预览 -> 应用”流程。所有 Widget 都经过 Zod Schema 和白名单注册表校验，未知组件、任意 HTML 和任意 JSX 不会被渲染。

请求期间可取消；超时或失败后可重试。未配置 API Key 时，其他 Demo 功能仍可正常使用。

## 8. 非通用能力

### 8.1 Onboarding

- 按直播类型生成工作台。
- 支持自定义主题。
- 支持直接进入专业模式。

### 8.2 播前任务

- 画布布局确认。
- 画风检测建议。
- 标题和开场脚本预览。
- 互动开场配置。
- 准备度进度和 GO LIVE 流程。

### 8.3 移动端与 Studio 预览

- “移动端预览”用于观察竖屏观众侧效果。
- “Studio 视图”显示画布辅助线，并用于投屏和画中画编辑。

### 8.4 模拟 PK

- 双人画面、比分、倒计时和目标挂件。
- 用于展示直播流程，不包含真实连麦、推流或服务端结算。

### 8.5 动态评论与礼物

- 评论、礼物、观众数和进房数据按固定节奏变化。
- 不同演示场景使用不同评论语料。
- 评论关键词结果可驱动排障建议。

### 8.6 安全预览与撤回

- 画面、音频、美化、投票和 LIVE Goal 均支持预览。
- 应用后保留上一次正式状态，可执行一次撤回。
- 切换场景时清理未提交预览，避免临时参数污染正式状态。

## 9. 比赛演示建议顺序

1. 首页选择“音乐现场”，输入主题并召唤 Genie。
2. 快速完成四个播前任务并 GO LIVE。
3. 展示真实亮度、麦克风和人像占比。
4. 开启游戏投屏，拖拽并缩放摄像头画中画。
5. 展示一套美颜、美妆、虚拟背景和人脸道具组合。
6. 使用 Genie 输入明确数值，演示动态组件生成、预览和应用。
7. 发布点歌投票并点击选项。
8. 发起 PK，发布 LIVE Goal，并用模拟礼物完成目标。
9. 切换到“排障”，展示评论关键词和麦克风调节。

## 10. 后续建设优先级

1. 接入真实直播间事件 Adapter，替换进房、评论、礼物和在线人数 Mock。
2. 扩展观众画像 Schema，增加性别和年龄区间统计。
3. 新增独立“观众心愿”组件，支持自由文本收集、聚类、点赞、置顶和完成状态。
4. 将播前场景模板真正映射到可持久化画布配置。
5. 接入真实推流和 PK 服务端能力。
